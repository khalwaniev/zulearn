# Independent mastery gates

## For a mathematical topic
Unseen closed-book proofs/derivations + counterexamples + numerical verification + delayed recall.

## For a deep-learning architecture
From-scratch component + gradient/unit tests + scaling/memory calculation + failure analysis + controlled ablation.

## For scientific methods
Correct domain assumptions + data provenance + validation defensibility + uncertainty quantification + downstream interpretation.

## For algorithms
Correctness argument + complexity + edge tests + time-bounded unseen implementation.

## For research
Falsifiable question + protocol frozen before evaluation + complete log + negative controls + replication + critical peer discussion.

## Scores (proposed operational rubric; not external validated scale)
0 = cannot begin; 1 = assisted; 2 = partially independent; 3 = independent unseen task; 4 = independent task + principled extension and critique.
Pass: 3+ twice on distinct tasks separated by time. A self-rating alone never certifies mastery.

## Metrics to report publicly
Number of *independently* passed gates; number of credible reproductions; published code with tests; papers critically reviewed; original contributions with limitations. Never equate watch-hours or raw solved count with expertise.
