# One authoritative Zulearn curriculum

> Version 1, 2026-11-27: bounded corrective revision after human-reported conditional independent approval. Curriculum architecture fixed for learning; local queues and learner evidence remain adaptive. Live GitHub integration awaits approval of this revised package.

The objective is independently demonstrated, transferable scientific competence per focused hour, preserving PhD research preparation under Professor Jürgen Schmidhuber and research-relevant ARC/CASP/CAFA competence. Independent mathematical discovery, algorithm invention, architecture design and scientific experimentation remain the outcomes. The path supports AGI, recursive self-improvement, reasoning, mechanistic interpretability and AI for Science. Deep-Path is the default ML navigation spine; the competency registry governs prerequisites and exemptions. TensorTonic provides selected complementary practice. A platform's advertised coverage is evidence of available material, not learner mastery or validated teaching effectiveness.

## Scope and decisions

| Category | Meaning | Examples and action |
|---|---|---|
| REQUIRED PREREQUISITE | The needed local operation must be understood before it is used; teach it inline when possible | Algebra/functions before differentiation; Python before implementation |
| REQUIRED CORE | Shared research foundations | Proof, linear algebra, probability, inference, algorithms, classical/DL methods, foundational RL, evaluation |
| LEARN IN PARALLEL | Deepen while using an already sufficient entry level | Proof, numerical analysis, statistics, communication and reproducibility |
| RESEARCH SPECIALIZATION | Required only when that branch is active | Gödel-machine assumptions, causal circuit analysis, protein biophysics |
| OPTIONAL | Adds useful challenge without displacing an unmet core need | A selected Putnam problem or alternative JAX implementation |
| DEFERRED | Has a stated re-entry trigger | Robotics-heavy RL; distributed MoE training without a scale bottleneck |
| REDUNDANT | Same competence already demonstrated | Second guided implementation of an already passed gradient descent exercise |
| EXCLUDED | Outside the current scientific scope | Trading/betting applications; commercial marketing analytics |

Foundational RL is REQUIRED CORE for sequential decision making, exploration, planning, policy/value methods and world models. This follows the recovered synthesis and supersedes broad RL deferral **inside this proposed package**. Continuous-control specialism and application-specific RL remain deferred. Finance-context exercises are excluded while their general mathematical content may be learned through a suitable non-finance task.

## Concurrent, prerequisite-aware progression

Only the four basic operations are provisionally fluent; other arithmetic topics are not assumed. No subsequent mastery is inferred. Begin with fraction meaning/equivalence and Python; teach the other arithmetic extensions systematically, then elementary algebra and formal mathematics. The learner sees one next lesson, not the entire registry. Entry operations and depth dependencies are separate in the [registry](COMPETENCY_REGISTRY.md); module completion is not a global admission gate.

| Progression | Mathematics lane | Programming/DSA and ML lane | Evidence and next action |
|---|---|---|---|
| Start now | Fractions → decimals → ratios/percent → signed numbers → powers/order; no mastery of these assumed | Python assignment/output with whole numbers; lists/loops in parallel | START-01 teaches fraction meaning/equivalence first; a short changed task after teaching |
| Foundations | Intermediate algebra, inequalities, functions, exponents/logs, geometry/trig, sequences/series | Functions, scans, dicts, basic algorithms and experimental data reasoning | Advance the demonstrated subskill; repair only the operation that failed |
| University core | Proof/discrete math, matrices, derivatives, finite→continuous probability, inference and numerics | Statistical ML, algorithm correctness/complexity, autodiff/DL as relevant mathematics is learned | One derivation/implementation/meaningful variation; delayed independent sample |
| Deeper methods | Jacobians/Hessians/Taylor error, concentration, optimization, MC/VI, fixed points and information | Attention/LMs, tabular RL→approximation, planning, GNNs, separate generation/SSL and post-training/verifiers | Gate the actual claim/method, not every preceding entire course |
| One active frontier branch | Analysis/geometry/dynamics/AIT or domain science as the question demands | AGI, RSI, reasoning, MechInt or AI for Science; remaining branches are reference queues | One narrowed question, relevant paper mechanism, controlled test and external criticism |

Mathematical discovery and counterexample search recur from the first week; rigorous proofs develop alongside formal instruction. Introductory ML and both learning platforms remain accessible for tasks whose local operations are ready. No requirement to finish all foundational mathematics before touching Deep-ML/TensorTonic is retained.

## Exact next-action rule

1. Open [START-01 and the first-week queue](../operations/WEEKLY_DAILY_WORKFLOW.md). Begin the lesson; no global diagnostic is required.
2. Use the specified explanation/example and the medium listed there. If the learner asks to accelerate, one or two relevant independent examples can replace repeated routine teaching.
3. Check only the subskill just used. Diagnose notation, arithmetic, conceptual, code and proof errors separately; provide immediate explanation/practice and a changed attempt.
4. Keep meaningful practice that changes assumptions, representations, constraints or reasoning demand. Skip a duplicate only after appropriate independent evidence, not merely because it shares a topic tag.
5. The tutor records help and a concise result in optional [learner state](../templates/LEARNER_STATE.md), then supplies one exact next task; the learner need not fill a form. AI-assisted success is not independent mastery.
6. Retrieve later and adapt pace. Do not re-open curriculum design unless a demonstrated gap or active research requirement demands it.

The larger diagnostic questions/key remain a reference bank for locally relevant later samples. Their `DX-` labels are separate from worksheet IDs. A final mixed assessment is optional evidence at a meaningful milestone, not a prerequisite to starting learning.

## Exercise budget and exemptions

Start with one primary explanation and representative practice for the current subskill. Add a derivation, implementation or transfer variation when that task requires it; no code/proof formality is required for every first arithmetic lesson. Increase practice only after a mistake, weak explanation, slow basic execution, failed retention, or a new task demand. Skip a guided duplicate after the independent gate succeeds. Completing all 3,185 path occurrences, both platforms, entire book collections, or multiple introductory courses is not required. No mastery exemption follows from degrees, publications, leaderboard scores, or AI-assisted output alone.

Read the [precise mathematics sequence](MATHEMATICS.md) for chapter/lecture selections and original problem sheets. The [112-concept map](DEEP_PATH_CONCEPT_MAP.md) assigns every exported Deep-Path concept a role; mixed units are filtered at task level. Unavailable projects have explicit fallbacks.

## First session and week

START-01 teaches fraction meaning/equivalence and optional whole-number Python assignment/output. START-02–06 teach further arithmetic extensions; START-07 begins notation/equality. These are visits, not a one-week arithmetic-completion claim. START-02–07 supply exact OpenStax/Python/platform locators, original practice, recurring discovery, separate local checks, remediation and next actions. The learner does not need to choose sources each morning. Slow progress carries a lesson forward without halting unrelated lanes; demonstrated knowledge permits local acceleration.

After the first queue, finish any missing arithmetic extension locally and follow the systematic algebra sequence. Only F01.basic_ops was assumed; none of the extension outcomes is pre-awarded. All later reading is selective and tied to the registry. The [AI learning engine](../operations/AI_LEARNING_ENGINE.md) is a small tutoring/state protocol using existing tools, not a new software build. The [bounded curriculum crosswalk](../governance/CURRICULUM_CROSSWALK.md) verifies AI-relevant breadth without importing five full degree programs.
