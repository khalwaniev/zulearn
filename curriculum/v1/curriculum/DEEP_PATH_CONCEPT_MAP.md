## Sequence corrections and observed blockers

- D003 data/splits/baselines should accompany or precede the first D002 empirical evaluation; the catalogue order is not a universal prerequisite theorem.
- D104–107 algorithm foundations run early alongside mathematics and ML, before dependent search/program-synthesis work; they do not wait for the end of the 112 concepts.
- D075 policy gradients and relevant value-estimation foundations precede D056 PPO/GRPO work. The export itself flags a Part 5 prerequisite; the exact wording of that older unit label does not perfectly match the current concept title. This package maps to the actual necessary competencies L18–L20 rather than inventing a renamed unit.
- D006 explicitly says its statsmodels project is built but held because that dependency is missing. Learn inference using the existing math/problems and original S1–S3 sheets; implement the needed simple model locally if appropriate. Do not claim the hosted project ran.
- D009 similarly reports a lifelines-dependent project on hold. This is a conditional scientific specialization, so the blocker does not stall the common core.
- D023 mixes general temporal modeling with financial ML: select only transferable scientific temporal-validation content; exclude trading/betting tasks. D101–102 and D088–091 likewise require task-level filtering.
- D039 includes autoencoders, GANs and contrastive methods: the common-core gate requires understanding one generative and one useful representation-learning objective, not completing every family. D068 world-model concepts do not impose full video-scale training.
- “No lab/project for this concept yet” means absent in the snapshot, not permanently unavailable. Premium/access fields of inner steps remain to be verified at assignment time.

All categories are proposed competency allocations; an item can be redundant for a particular learner after an independent gate. Stage entry follows the registry, not a rigid increasing-ordinal traversal.
