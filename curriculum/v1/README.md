# Zulearn Programme — final curriculum v1

> Version 1, 2026-11-27: bounded corrective revision after human-reported conditional independent approval. Curriculum architecture fixed for learning; local queues and learner evidence remain adaptive. Live GitHub integration awaits approval of this revised package.

**Start with fractions.** Only basic addition, subtraction, multiplication and division are assumed fluent. Open [the first session](operations/WEEKLY_DAILY_WORKFLOW.md#start-01--todays-complete-lesson-what-a-fraction-means): equal-parts drawings and equivalent fractions, with optional whole-number Python assignment/output. Decimals, percentages, ratios, negative numbers, exponents and other arithmetic topics are taught in the fixed next queue, then elementary algebra. No preliminary exam or administrative setup is required. The learner sees one lesson, a short practice/check and one explicit next action; the detailed curriculum stays in the background.

The learner reports conditional independent adversarial approval of the reconstructed baseline and requested the P01–P12 corrective pass. [The correction manifest](governance/FINAL_CORRECTION_MANIFEST.md) verifies each finding and records closure evidence. V1's architecture is fixed for learning; learner state, pace and equivalent resource substitutions remain adaptive. The live GitHub repository has not been modified and still requires approval of this revised package before integration.

The goals remain PhD research preparation under Professor Jürgen Schmidhuber; AGI, RSI, reasoning, mechanistic interpretability and AI for Science; research-relevant ARC/CASP/CAFA competence; and independent mathematical discovery, algorithm invention, architecture design and scientific experimentation. No admission, publication, benchmark result or learner mastery is promised.
