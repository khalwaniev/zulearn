## Adversarial failure modes and concrete tests

| Failure hypothesis | How this package addresses it | Independent reviewer should try |
|---|---|---|
| “Recovery” disguises newly invented original deliverables | Exact source report separated; every new document labelled reconstructed | Compare source report/native hash and locate any unsupported claim of original wording |
| Catalogue completion replaces competency formation | One registry and selection/exemption rules | Find a mandatory task justified only by a badge/count |
| Hidden prerequisite cycles or impossible route | Explicit DAG; short entry bridge; parallel independent work | Trace novice and advanced learners through the graph and attempt to create a dead end |
| Diagnostic underestimates gaps or becomes a giant exam | Teach START-01 first, short local subskill checks and immediate remediation; no global pass score | Test route on a strong programmer/weak mathematician and the reverse profile |
| Answer key is wrong or access separation inadequate | Separate examiner copy and exposure policy; reference snippets/calculations checked | Recalculate every item; inspect rubric fairness and leaked-assessment reuse |
| Platform ecosystem is underestimated | Supplied six exports, all 112 concepts and new TensorTonic prompts | Identify a core skill wrongly assigned external work despite adequate internal evidence |
| False exact overlap or invented IDs | Local ordinal aliases, explicit UNKNOWN and constraints-based taxonomy | Locate any duplicated-item claim based only on titles |
| Mathematics is either shallow or unnecessarily broad | Independent derivations, curated external sections, specialist triggers | Find a core skill without proof/transfer assessment or a needless advanced gate |
| Olympiad/Putnam is treated as proven far-transfer training | Selective bounded proof-discovery hypothesis | Remove prestige language and ask whether the task still serves a named reasoning move |
| RL remains improperly excluded or expands without limit | Foundational RL core, specialist robotics/scale conditional | Check L18–L21 suffice for first planning study without every deep-RL variant |
| Paper implementation is called reproduction | Separate R/D/I/P/X and claim contract | Find a toy project labelled as a full headline reproduction |
| MechInt causal claims exceed interventions | Probe/intervention distinction and negative controls | Construct an off-manifold/alternative-mechanism explanation of the proposed study |
| Biological evaluation ignores domain science | B modules, homology/date/GO semantics and uncertainty | Try a sequence/template/annotation leakage scenario and a nonpropagating GO relation |
| Sleep/workload/threshold heuristics are falsely scientific | Evidence and local design separated | Locate a universal “optimal” hour, spacing interval or passing percentage |
| AI assistance hides lack of independent ability | Assistance logs, new tasks, no-AI assessment | Ask for a derivation/code reconstruction with model access removed |
| Future competitions/admissions are invented | Official checks + conditional unknowns; no interview syllabus | Locate a claimed unreleased ARC format or confirmed future lab availability |
| Existing repo will contain competing roadmaps | Manifest proposes future pointer/retirement changes | Verify every conflicting legacy file has a disposition before integration |

## Overlooked competencies now explicit

Measurement validity, the data-generating process, numerical conditioning, input/target alignment, calibration under shift, dependent resampling, adaptive-selection bias, causal identification, computability, synthesis, trusted-base limits, annotation uncertainty, GO relation semantics, homology/template/time leakage, experimental validation, efficiency accounting and external criticism are taught/assessed rather than left implicit. Their inclusion is justified by ways they can invalidate research. This does not make all domain science a prerequisite to every first ML task.

## Unresolved material limits

Full TensorTonic/Essentials inner inventories, platform schedule efficacy, exact global overlap, learner placement, diagnostic calibration, and some blocked full texts remain unresolved. These are not filled with fabricated IDs, content or effect estimates. A conditional allocation can be operationally complete without an exhaustive closed-world catalogue. An activated task must still have a real source and an assessable objective.

## Additional v1 adversarial checks

- Only F01.basic_ops is assumed: basic addition/subtraction/multiplication/division. Fractions, decimals, percentages, ratios, negatives, exponents and other arithmetic skills are new until demonstrated. START-01 teaches fraction meaning/equivalence; Python starts with whole numbers. Algebra follows systematically, with extensions taught locally as used. A programmer can continue DSA while repairing mathematics; a mathematician can begin Python without an algebra-completion formality.
- Finite probability is not blocked by calculus, tabular TD by neural networks, tabular planning by video/generative modeling, or leakage literacy by full structure prediction.
- Diagnostic labels match actual demands; no implementation credit comes from a noncoding prompt. Mixed questions are scored at subskill level.
- Generation/SSL and SFT/reward/preference/verifier roles have separate evidence; a guided build or evaluator agreement is not a reproduced claim or proof.
- Recurring discovery starts with simple examples/counterexamples and scales with actual readiness, without promising far transfer from prestige contests.
- Source limitations in the bounded five-program crosswalk and tutoring repositories remain explicit. Owner theories and dynamic catalogue metadata are not represented as controlled efficacy evidence.
