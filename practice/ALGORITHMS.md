# Algorithmic practice policy

## Primary: selective LeetCode
Target 150–250 **carefully chosen problems** over time, NOT all problems. Initial distribution (modifiable):
- 35 arrays / hashing / two-pointers / binary search
- 30 graphs (BFS/DFS/shortest path/union-find/topological sort)
- 30 dynamic programming and memoization
- 20 heaps / trees / priority queues
- 20 strings / tries / parsing / suffix methods
- 15 numerical/matrix/geometry problems
- 20 mixed hard problems relevant to matching, assignment or scientific algorithms

The categories overlap; the counts form an approximate starting syllabus, not mandatory quotas.

## Conditional competition platforms
- Codeforces: **optional**, use selected Div 2 C/D/E-style tasks or educational rounds when a specific bottleneck arises. No ranking chase.
- AtCoder: **optional**, particularly Educational DP or mathematical/programming tasks.
- CodeChef, Topcoder, HackerRank, HackerEarth: **ignore by default**; use only if they offer a genuinely unique relevant problem.

## Must-have research algorithms
Complexity analysis, graphs, shortest paths, DP, union-find, topological sorting, bipartite matching, maximum flow, integer programming, approximations, efficient indexing, vectorized kernels, numerical optimization.

## Evaluation
Unseen timed implementation; proof of correctness; upper bounds; memory analysis; independently generated test cases.
